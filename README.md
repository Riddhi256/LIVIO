# Livio

A full-stack travel listing web application inspired by Airbnb.

## Features

- User Authentication
- CRUD Listings
- Reviews and Ratings
- Image Uploads using Cloudinary
- Interactive Maps using Leaflet and OpenStreetMap
- Search Functionality
- Session Management

## Tech Stack

- Node.js
- Express.js
- MongoDB Atlas
- EJS
- Bootstrap
- Passport.js
- Cloudinary
- Leaflet
